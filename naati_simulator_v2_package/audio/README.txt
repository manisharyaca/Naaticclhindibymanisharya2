Optional HUMAN AUDIO PACK
=========================

The simulator can use actual human-recorded MP3 files instead of browser speech synthesis.

Folder structure:
  index.html
  audio/
    test001_d1_s01.mp3
    test001_d1_s02.mp3
    ...

Naming convention:
  testNNN_dD_sSS.mp3

Examples:
  Test 1, Dialogue 1, Segment 1: audio/test001_d1_s01.mp3
  Test 1, Dialogue 2, Segment 4: audio/test001_d2_s04.mp3
  Test 37, Dialogue 1, Segment 12: audio/test037_d1_s12.mp3

Use only audio you recorded yourself or have permission/licensing to host.
If an MP3 is missing, the simulator automatically falls back to the selected Australian browser voice.

For the best browser-generated Australian voice, open Dashboard and choose a voice labelled en-AU and, where available, Natural (for example a Microsoft Australian Natural voice).
