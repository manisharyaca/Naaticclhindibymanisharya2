Simulator rules

  • Two dialogues per full test.
  • Each dialogue begins at 45 marks.
  • Practice pass: 63/90 overall and at least 29/45 in each dialogue.
  • One repeat per dialogue is treated as penalty-free.
  • Response start beyond 5 seconds is flagged for delivery risk.
  • First-person/direct speech is expected.
  • The 20-minute performance clock counts dialogue recordings + your interpreting only.
  • Exam Mode hides source text and live transcription.
  • Cloud scoring uses dual transcription and semantic meaning evaluation when configured.

Scoring limitations

This file provides NAATI-aligned practice scoring, not official NAATI examiner marking. Cloud mode uses two speech-to-text passes plus semantic meaning judging, entity checks and delivery/repeat logic. Local mode uses deterministic browser checks. Neither mode reproduces NAATI's proprietary examiner calibration.

For a production service, connect high-quality Hindi/English ASR, a second transcription pass, semantic LLM judging, deterministic entity checking and human-calibration data.

Audio & hosting

This is a single static HTML file. Upload it directly to Netlify Drop, GitHub Pages, Cloudflare Pages, Vercel static hosting, or any ordinary web server. Use HTTPS for microphone access.

The simulator prioritises installed English (Australia) voices and prefers voices labelled Natural when the browser exposes them. Browser speech synthesis is still synthetic. For actual human Australian speech, select the optional human-audio mode and host your own/licensed MP3 recordings in the audio/ folder.
