NAATI CCL HINDI SIMULATOR V5 — GITHUB REPOSITORY REPLACEMENT
=============================================================

IMPORTANT
---------
Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Do NOT upload this whole folder as a nested folder.
Do NOT upload the ZIP itself to GitHub and expect GitHub Pages to extract it.

Your repository root should look exactly like this after replacement:

index.html
netlify.toml
README.md
audio/
    README.txt
netlify/
    functions/
        health.mjs
        score.mjs
        transcribe.mjs
        tts.mjs

FOR YOUR CURRENT REPOSITORY
---------------------------
1. Delete the old folder: naati_simulator_v2_package/
2. Replace the existing root index.html with the new index.html in this package.
3. Replace/update README.md if desired.
4. Add netlify.toml at repository root.
5. Add the netlify/functions/ folder and all four .mjs files.
6. Add audio/README.txt so the audio folder is retained by Git.
7. Commit the changes to main.

GITHUB PAGES VS FULL V5
-----------------------
GitHub Pages can display the simulator frontend, but it cannot execute the included
server-side AI transcription/scoring/TTS functions.

For full V5 functionality, connect this SAME GitHub repository to Netlify and deploy
from the repository. Then add OPENAI_API_KEY as a Netlify Environment Variable.
Never place the API key in index.html or commit it to GitHub.

Recommended Netlify settings:
Build command: leave blank
Publish directory: .

Then redeploy and use the simulator's "Check cloud engine" control.

No API key is included in this package.
